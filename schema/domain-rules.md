# 领域规则页

> LLM ingest 时必读。本页定义领域阈值规则、ingest 判断流程、索引维护规范。实际领域清单见 [[wiki/index.md]]。

## 阈值规则

1. **一级领域**：页面数 ≥1 即存在。新领域（schema 中未定义）即使只有 1 页也立即建立（如医学）。
2. **子领域（二级及以下）**：父领域下某子主题页面数 **>=5** 时才建立。已建立的子领域不可撤销（即使页面数回落）。子领域不能与已有的一级领域同名。
3. **跨领域上限**：单个页面最多归属 **4 个**领域路径。
4. **路径式表达**：`domain: [编程/Python, AI/Agent, 思维工具]`，斜杠分隔层级，无斜杠即一级。支持任意深度（理论上一级/二级/三级...）。

## 领域清单

一级领域清单和子领域清单见 [[wiki/index.md]] 的"领域目录"和"子领域清单"章节。本页只维护规则和流程。

## ingest 判断流程

1. **读 [[wiki/index.md]]**：了解已建立的领域框架（领域目录 + 子领域清单）
2. **判断一级归属**：本页内容属于哪些已定义领域？是否属于未定义的新领域？
   - 跨领域最多 4 个路径
   - 新领域（如医学）：立即建立，加入 [[wiki/index.md]] 领域目录，新建对应分表文件
3. **判断子领域归属**（仅当一级领域已有子领域时）：本页是否属于某个已建立的子领域？
   - 是 -> 写子领域路径（如 `domain: [编程/Python]`）
   - 否 -> 写一级路径（如 `domain: [编程]`）
4. **阈值检查**（每次 ingest 都做，针对相关一级领域）：
   - 读父领域分表，扫视"未归类到子领域"的页面（即 domain 字段为 `[xxx]` 而非 `[xxx/yyy]` 的页面）
   - 按子主题聚类计数
   - 某子主题 >=5 篇 -> 建子领域：更新 [[wiki/index.md]] 子领域清单 + 新建子领域分表（连字符命名，如 `编程-Python.md`）+ 迁移相关页面 domain 字段（`[编程]` -> `[编程/Python]`）+ 从父领域分表移除已归类行
5. **同步更新**：[[wiki/index.md]] 领域目录/子领域清单 + 父领域分表 + 子领域分表（如新建）+ [[wiki/index.md]] 矩阵

## 子领域分表文件规范

- 命名：连字符，如 `编程-Python.md`、`编程-Python-异步.md`（三级）
- frontmatter：`type: domain-index`、`domain: 编程/Python`（路径式）、`level: 2`、`parent: 编程`、`title`、`created`、`updated`
- 正文结构同一级分表：标题 + 描述 + 页数 -> Sources/Entities/Concepts/Comparisons 四类表格

## 索引维护规范

创建/更新/删除页面后，同步更新 `[[wiki/index.md]]` 交叉矩阵和 `wiki/domains/` 相关分表。

**新增页面：**
- 同步更新 `wiki/index.md` 交叉矩阵：对应领域 × 对应类型的单元格 +1，小计 +1
- 同步更新 `wiki/domains/` 中所有受影响的分表：在对应类型表格添加一行
- 若页面包含全新领域（`wiki/domains/` 中尚无对应文件）：创建分表文件（用 [[schema/templates.md]] 的 Domain Index 模板），同时在 `wiki/index.md` 交叉矩阵和领域目录各加一行

**修改页面 domain（含 ingest 更新和 enrich 反哺）：**
- 若 domain 新增了一个领域：在 `wiki/index.md` 交叉矩阵中该领域行对应类型 +1；在新领域的分表中添加该页面行
- 若 domain 移除了一个领域：在 `wiki/index.md` 交叉矩阵中该领域行对应类型 -1（归零则删该行）；从该领域分表中移除该页面行
- 若 domain 完全变更（替换）：等同于先移除再新增，两步都执行

**删除页面：**
- 从 `wiki/index.md` 交叉矩阵所有相关领域行中对应类型 -1（归零则删该行）
- 从 `wiki/domains/` 所有相关分表中移除该页面行
- 领域分表中最后一个页面被移除后，该域行从交叉矩阵消失，但分表文件保留（保留领域元信息）

**领域重命名/合并/拆分：**
- 需用户显式发起，LLM 不自动做域名变更
- 执行时：更新所有受影响页面的 frontmatter `domain` -> 重建受影响的 `wiki/domains/` 分表文件 -> 重算 `wiki/index.md` 交叉矩阵

**子领域相关：** 新建子领域时同步更新 [[wiki/index.md]] 子领域清单 + 父领域分表 + `wiki/index.md` 矩阵（矩阵只展一级，一级领域行页数不变）。
